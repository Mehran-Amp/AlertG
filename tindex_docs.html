وب‌سرویس و API تیندکس

دسترسی برنامه‌نویسی رایگان به همهٔ داده‌های اقتصادی و مالی تیندکس (شاخص‌ها، بورس تهران، نرخ ارز، اخبار، تورم و مسکن) با توکن شخصی خودتان. این صفحه مرجع کامل ۹ اندپوینت API با نمونه‌کد و نمونه‌پاسخ واقعی است.

شروع سریع

API تیندکس رایگان است، اما برای استفاده از آن به یک توکن دسترسی نیاز دارید. سه قدم ساده:

  1. یک حساب کاربری بسازید و نشانی ایمیل خود را تأیید کنید.
  2. از داشبورد، یک توکن API بسازید (حداکثر ۱ توکن هم‌زمان در پلن رایگان).
  3. توکن را در هدر Authorization: Bearer … هر درخواست قرار دهید.
ساخت حساب رایگاندریافت توکن API

فقط می‌خواهید قیمت‌ها را روی سایتتان نشان دهید؟

برای نمایش قیمت روی یک صفحه، به توکن و کدنویسی نیازی نیست. با سازندهٔ ویجت یک قطعه HTML بردارید و بچسبانید، قفل‌شده روی دامنهٔ خودتان و بدون هیچ وابستگی.

سازندهٔ ویجت

احراز هویت

توکن خود را در هدر Authorization هر درخواست قرار دهید. همهٔ مسیرها نسبت به آدرس پایهٔ https://tindex.app هستند. همهٔ درخواست‌ها به /api/public/* باید توکن معتبر داشته باشند؛ درخواست بدون توکن با پاسخ 401 رد می‌شود. دورهٔ آزمایشی بدون توکن دیگر وجود ندارد.

توکن‌ها منقضی نمی‌شوند مگر خودتان برایشان تاریخ انقضا تعیین کنید یا از داشبورد باطلشان کنید. هر توکن فقط ابیلیتی developer دارد و برای اندپوینت‌های اپلیکیشن موبایل تیندکس کار نمی‌کند (و برعکس).
curl
curl -H "Authorization: Bearer YOUR_TOKEN" \
     -H "Accept: application/json" \
     https://tindex.app/api/public/currency-rates
JavaScript (fetch)
const res = await fetch('https://tindex.app/api/public/currency-rates', {
  headers: {
    Authorization: 'Bearer YOUR_TOKEN',
    Accept: 'application/json',
  },
});
const { success, data } = await res.json();

if (success) {
  console.log(data); // فهرست نرخ‌های ارزی
}
Python (requests)
import requests

resp = requests.get(
    "https://tindex.app/api/public/indicators/by-category/precious-metals",
    headers={
        "Authorization": "Bearer YOUR_TOKEN",
        "Accept": "application/json",
    },
)
payload = resp.json()
if payload["success"]:
    print(payload["data"]["rows"])
PHP (cURL)
$ch = curl_init('https://tindex.app/api/public/currency-rates');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer YOUR_TOKEN',
        'Accept: application/json',
    ],
]);
$payload = json_decode(curl_exec($ch), true);

زبان پاسخ

همهٔ اندپوینت‌های داده پارامتر اختیاری lang را می‌پذیرند. برای نام‌ها، واحدها، تاریخ‌ها و متن‌های نمایشی انگلیسی از lang=en و برای فارسی از lang=fa استفاده کنید. فقط وقتی مقدار انگلیسی منبع وجود نداشته باشد، پاسخ انگلیسی به مقدار فارسی برمی‌گردد.

نامنوعپیش‌فرضتوضیح
langfa | enfaزبان پاسخ. برای حفظ پاسخ فارسی سازگار با نسخه‌های قبلی، آن را حذف کنید.
curl -s "https://tindex.app/api/public/boards?lang=en" \
  -H "Authorization: Bearer YOUR_TOKEN"
حذف lang دقیقاً معادل lang=fa است. تیندکس هرگز زبان پاسخ را از Accept-Language انتخاب نمی‌کند. زبان حل‌شده در هدر پاسخ Content-Language هم اعلام می‌شود.

قالب پاسخ و خطا

هر پاسخ موفق این قالب را دارد:

{ "success": true, "data": ... }

اندپوینت‌های صفحه‌بندی‌شده (غربالگر بورس، news در حالت صفحه‌بندی‌شده) یک شیء meta هم اضافه می‌کنند. جزئیات در بخش «صفحه‌بندی» پایین همین صفحه.

پاسخ ناموفق:

{ "success": false, "message": "..." }

خطاهای سطح احراز هویت و محدودیت نرخ (۴۰۱، ۴۰۳، ۴۲۹) برای سازگاری همان قالب دوزبانه را نگه می‌دارند: message فارسی، message_en انگلیسی و لینک docs. خطاهای سطح منبع (مثلاً 404 برای slug نامعتبر) فیلد message را مطابق lang برمی‌گردانند. جدول کامل در بخش «کدهای خطا» آمده است.

محدودیت نرخ درخواست

پلن رایگان (پیش‌فرض همهٔ حساب‌های جدید) شامل موارد زیر است:

  • ۱ درخواست در دقیقه به‌ازای هر کاربر
  • ۱۰۰ درخواست در روز
  • حداکثر ۱ توکن فعال هم‌زمان
سقف بر اساس حساب کاربری شمرده می‌شود، نه توکن. اگر چند توکن بسازید (مثلاً یکی برای محیط توسعه و یکی برای محصول نهایی)، همهٔ آن‌ها یک سهمیهٔ مشترک را مصرف می‌کنند.

هر پاسخ، صرف‌نظر از موفق یا ناموفق بودن، این هدرها را همراه دارد:

هدرتوضیح
X-RateLimit-Limitسقف مجاز در پنجرهٔ زمانی جاری (دقیقه یا روز)
X-RateLimit-Remainingتعداد درخواست باقی‌ماندهٔ همان پنجره
Retry-Afterفقط روی پاسخ ۴۲۹؛ چند ثانیه دیگر صبر کنید

وقتی از سقف عبور کنید، پاسخ زیر را با کد وضعیت ۴۲۹ دریافت می‌کنید:

{
  "success": false,
  "message": "سقف درخواست‌های پلن شما در این دقیقه پر شده است.",
  "message_en": "Rate limit exceeded for your plan. See the X-RateLimit-* headers.",
  "retry_after": 42,
  "docs": "https://tindex.app/developers/"
}

در صورت عبور مکرر از سقف چه اتفاقی می‌افتد؟

  • هر درخواست اضافه فقط با 429 رد می‌شود؛ هیچ جریمهٔ خودکار یا بن موقتی روی حساب اعمال نمی‌شود و به‌محض شروع پنجرهٔ بعدی (دقیقه/روز) دوباره می‌توانید درخواست بزنید.
  • درخواست‌هایی که با ۴۲۹ رد می‌شوند، در سهمیهٔ روزانهٔ شما شمرده نمی‌شوند؛ فقط درخواست‌های موفق مصرف حساب می‌شوند.
  • اگر تیندکس تشخیص دهد استفاده از توکن با شرایط استفادهٔ منصفانه مغایرت دارد (نه صرفاً عبور از سقف نرخ)، دسترسی API آن حساب می‌تواند به‌صورت دستی توسط تیم تیندکس غیرفعال شود که پاسخ آن 403 (نه ۴۲۹) با پیام «دسترسی API برای این حساب غیرفعال شده است.» است.
  • برای سقف بالاتر لازم نیست منتظر بمانید: از صفحهٔ توکن‌های API در داشبورد می‌توانید درخواست ارتقا ثبت کنید.

چطور سقف بالاتری بگیرم؟

ارتقای سقف پرداختی نیست. چهار مسیر وجود دارد و هر درخواست دستی بررسی می‌شود؛ ثبت درخواست از صفحهٔ توکن‌های API انجام می‌شود.

  • ارجاع به منبع: هرجا داده را نمایش می‌دهید «منبع داده: تیندکس» را با لینک به tindex.app بیاورید و نشانی همان صفحه را بفرستید. سریع‌ترین مسیر.
  • پژوهشی، دانشگاهی یا متن‌باز: پایان‌نامه، مقاله، پروژهٔ متن‌باز یا کار عام‌المنفعه؛ فقط پروژه را معرفی کنید.
  • تبادل تبلیغاتی: نمایش بنر یا ویجت تیندکس در سایت/کانال شما، یا همکاری محتوایی.
  • استفادهٔ تجاری و حجم بالا: اگر داده بخشی از محصول تجاری است، شرایط اختصاصی جداگانه هماهنگ می‌شود.

مصرف امروز و ۳۰ روز اخیر خودتان را می‌توانید از داشبورد توکن‌های API ببینید.

مرجع نمادها و دسته‌ها

بسیاری از اندپوینت‌ها فقط slug شاخص یا نماد را برمی‌گردانند (مثل USD-EXCHANGE-RATE برای دلار آمریکا). این بخش، معنای هر نماد فعال در تیندکس را نشان می‌دهد. جست‌وجوی slug به بزرگی/کوچکی حروف حساس نیست (مثلاً btc و BTC یکسان‌اند).

مرجع اندپوینت‌ها

همهٔ اندپوینت‌ها با متد GET فراخوانی می‌شوند و نیاز به هدر Authorization: Bearer … دارند. موارد زیر فهرست کامل API توسعه‌دهندگان است؛ سایر مسیرهای وب‌سایت تیندکس (جست‌وجو، ماشین‌حساب‌ها، فرم تماس و…) بخشی از این API نیستند.

بازارها و شاخص‌ها

۹ اندپوینت

نرخ ارز، طلا و سکه، رمزارز، شاخص‌های بورس و انرژی و سایر شاخص‌های تیندکس: دادهٔ لحظه‌ای و تاریخچه. همهٔ مبالغ ریالی این بخش از ۲۹ تیر ۱۴۰۵ به «تومان» گزارش می‌شوند (پیش‌تر ریال بود؛ مقادیر یک‌دهم شده‌اند و فیلد unit نیز «تومان» است).

GET/api/public/boardsچهار تابلوی برگزیدهٔ صفحهٔ اصلی (ارز، طلا و سکه، رمزارز، بورس و انرژی) در یک درخواست، هرکدام با ۶ نماد ثابت.+

نمونه درخواست

curl -s "https://tindex.app/api/public/boards" \
  -H "Authorization: Bearer YOUR_TOKEN"

صفحه‌بندی (meta)

اندپوینت‌هایی که فهرست بلندی برمی‌گردانند (غربالگر بورس، news در حالت صفحه‌بندی‌شده) یک شیء meta کنار data اضافه می‌کنند:

{
  "success": true,
  "data": [ /* آرایهٔ آیتم‌ها */ ],
  "meta": {
    "page": 1,
    "per_page": 20,
    "total": 812,
    "has_more": true,
    "last_page": 41
  }
}

page و per_page پارامترهای کوئری ورودی را هم می‌پذیرند (سقف هر کدام در جدول پارامترهای همان اندپوینت آمده است). برای عبور از تمام صفحات، has_more را چک کنید یا page را از ۱ تا last_page افزایش دهید.

اگر رفتاری غیرمنتظره در پاسخ‌ها دیدید، به داده‌ای نیاز دارید که در این مرجع نیست، یا برای نرخ درخواست بالاتر/استفادهٔ تجاری هماهنگی لازم دارید، از طریق فرم تماس تیندکس با ما در ارتباط باشید. لطفاً مسیر دقیق اندپوینت و (در صورت وجود پاسخ خطا) کد وضعیت و بدنهٔ کامل پاسخ را همراه پیام خود بفرستید تا سریع‌تر بررسی شود.
